Project Title: Devsphere – A Unified Developer Platform

Name: Bhagya Sharma
Roll No: 2210990210

Description:
Devsphere is a web-based platform built using Next.js that allows developers to authenticate via GitHub, fetch profile data, create blogs, showcase projects, and view live deployed applications within a unified interface.

Motivation:
To eliminate fragmentation in developer portfolios by combining GitHub data, blogs, and live demos into a single platform.

Key Features:

* GitHub Authentication
* Profile Data Integration
* Blog Creation System
* Project Showcase
* Live Deployment Preview (Vercel)

Directory Structure:

* Source_Code: Contains project code
* IPR_Document: Copyright and submission files
* Report_Presentation: Report and PPT
